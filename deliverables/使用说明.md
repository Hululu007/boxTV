# boxTV 使用说明（电脑端便携版 v1.2.3 / 电视端 v1.3.14）

局域网视频共享方案：电脑端 boxTV Host（授权后台 + 视频服务）+ 电视端 boxTV（浏览与播放）。

> 2026-11-09 起电脑端改为**免安装绿色便携版**：解压即用，无需安装；升级仅需替换解压目录内文件。

## 一、系统要求

| 端 | 要求 |
|---|---|
| 电脑端 | Windows 10/11 x64（无需安装 Java，包内自带运行时） |
| 电视端 | Android TV / 盒子，Android 10（API 29）及以上 |
| 网络 | 双端处于**同一局域网** |

## 二、电脑端安装与配置

1. 解压 `boxTVHost-1.2.3-portable-win64.zip` 到任意目录（如 `D:\boxTV\`，得到 `boxTVHost\` 文件夹）。
2. 双击 `boxTVHost\boxTVHost.exe` 启动（可右键发送到桌面快捷方式，方便日常使用）：
   - 标题栏显示「服务运行中 :8964」即服务就绪；
   - 关闭窗口默认最小化到系统托盘（可在设置中修改）；托盘图标双击可唤起。
3. **授权文件夹**：左侧栏点击「添加」选择要共享给电视的视频文件夹（可添加多个）。
4. **Windows 防火墙放行**（电视端发现与访问的前提）：
   - 首次运行 Windows 可能弹出防火墙授权提示，请勾选「专用网络」并点击「允许访问」；
   - 或在「设置 → Windows 防火墙」中查看状态，点击「一键放行（弹出系统授权确认）」并在 UAC 中确认；
   - 手动放行（管理员命令行执行）：
     ```bat
     netsh advfirewall firewall add rule name="boxTV Host" dir=in action=allow protocol=TCP localport=8964
     netsh advfirewall firewall add rule name="boxTV Host" dir=in action=allow protocol=UDP localport=8965
     ```
5. **可选设置**（设置页）：HTTP 端口（修改即时生效）、主机显示名、开机自启、关闭最小化到托盘。

### 电脑端升级（免安装，免卸载）

1. 关闭运行中的 boxTVHost（含托盘退出）；
2. 解压新版 zip，将解压得到的 `boxTVHost\` 目录内文件**覆盖替换**旧目录（或直接换用新目录）；
3. 重新运行 `boxTVHost.exe` 即完成升级。

- 配置、配对、缩略图缓存均保存在 `%APPDATA%\boxTV\`，与程序目录无关，替换文件不会丢失任何数据；
- 若升级后**目录路径发生变化**且已开启开机自启：请在设置中关闭再重新开启自启，以更新启动路径。

## 三、电视端安装与配对

1. 将 `boxTV-1.3.14.apk` 拷贝到电视/盒子（U 盘或 adb），文件管理器安装（侧载需允许「未知来源」）。
2. 打开 boxTV → 「添加主机」：
   - 自动搜索：选择发现的电脑（显示主机名与 IP:端口）；
   - 或「手动输入 IP」：格式 `192.168.1.100:8964`。
3. **配对**：
   - 电视端步骤 2 与电脑端顶部蓝色卡片**同步显示 4 位配对码**（5 分钟有效）；
   - 电视端输入配对码（输满 4 位自动提交）；
   - 电脑端点击「**允许并签发**」→ 电视端自动完成配对；点「拒绝」则电视端提示已拒绝，可重新获取配对码。
4. 配对成功后主页「我的主机」出现该电脑，点击进入浏览。

## 四、浏览与播放

- 顶部横向选择授权文件夹，网格显示子文件夹与视频；
- 视频卡片带缩略图（电脑端 ffmpeg 自动提取 10% 处关键帧；未生成/失败时显示占位图）；
- 点击视频 → 详情页（大小/时间/续播位置）→ 播放（支持拖动进度条、断点续播；进度 >95% 或 <5% 不续播）；
- 长按主页主机卡片可删除主机（删除后需重新配对）。

### 播放历史（电视端侧边栏「历史」）

- 侧边栏新增「历史」入口（主页/浏览页均可进入），展示全部播放过的影片；
- 每条记录展示：所属主机名、影片名、播放进度（`主机名 片名 进度xx%`）与视频缩略图；
- 打开历史页时自动校验：影片已从所有已配对电脑删除的记录自动隐藏；影片被迁移到其他电脑时自动在新主机上重新定位并展示；
- 点击历史条目 → 自动切换到影片所属主机并定位到上次进度续播（跨主机记录同样生效）；
- 头部「刷新」按钮：重新拉取各主机影片状态、重新校验全部历史条目并刷新列表；
- 记录按最近播放排序；从播放页返回时列表自动静默更新。

## 五、电脑端设备管理

- 「设备管理」页：列出已配对电视，点「断开授权」即时撤销（电视端下次访问收到 401 并自动清理，重新搜索可再次配对）；
- 「访问日志」页：查看浏览/播放/配对记录。

## 六、常见问题

| 问题 | 处理 |
|---|---|
| 电视端搜不到电脑 | 检查是否同一局域网；确认防火墙已放行 8964/TCP 与 8965/UDP；确认电脑端服务运行中。v1.3.13 起电视端内置「网段单播扫描」兜底（广播被个别电视/路由器过滤时自动启用，搜索最长约 10 秒）；若仍搜不到，多为路由器 AP 隔离/访客网络，请改用手动输入 IP |
| 连接成功但无法浏览 | 电脑端「设备管理」可能已断开授权，重新配对即可 |
| 缩略图不显示 | 属正常降级（视频编码不支持/文件损坏），不影响播放；推荐格式 H.264/MP4 |
| 播放卡顿/不支持 | 部分 HEVC/高码率文件硬解受限，建议转 H.264 MP4 |
| 想更换端口 | 设置页修改并「应用端口」，电视端需删除主机后用新地址重新配对 |
| 升级/移动电脑端 | 配置与配对数据保存在 `%APPDATA%\boxTV\`，替换程序文件自动保留；移动目录后如开启了自启需重新开启一次 |

## 七、技术参数

- HTTP 服务端口：8964/TCP（默认，可改）；UDP 发现端口：8965（固定）
- 通信协议：HTTP REST + 统一 JSON 信封；视频流支持 HTTP Range
- 安全：4 位配对码 + 32 位随机 Token（请求头 `X-BoxTV-Token`）；路径越界防护
- 缩略图：ffmpeg 捆绑于解压目录 `app\resources\tools\`，缓存 `%APPDATA%\boxTV\thumbCache\`
- 便携版程序结构：`boxTVHost.exe`（启动器）+ `app\`（应用与资源）+ `runtime\`（自带 JRE）
